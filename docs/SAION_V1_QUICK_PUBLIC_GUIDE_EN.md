## 1. What SAION Is

SAION is my performance notation and control system for AI music workflows.

It gives you practical control over:

1. Emotion
2. Vocal style
3. Timing feel
4. Phrase shape
5. Iteration quality

Simple formula I use:

Prompt + Performance Controls + Notation = Better Results

## 2. Fast Start

1. Name your session.
2. Write a clear prompt.
3. Set Emotion and Vocal controls.
4. Add light notation if needed.
5. Click Generate.
6. Listen fully once before changing anything.

## 3. The Most Important Controls

1. Emotion Controls
I use these to shape feeling and intensity.

2. Vocal Controls
I use these to shape delivery, texture, and timing.

3. Prompt Box
I use this to describe the creative goal in plain language.

4. Fine-Tune Notation
I use this for detail cues like breath, lift, and sustain.

5. Generate
I use this to render a new version.

## 4. A/B Workflow That Works

1. Save first good result as Version A.
2. Change only one or two settings.
3. Generate again and save as Version B.
4. Compare A and B.
5. Keep the stronger one.

This is the easiest way I know to improve quality without confusion.

## 5. Mini Notation Reference

| Symbol | Meaning | Example |
|---|---|---|
| ^ | Lift | ^hold^ |
| {b} | Breath | stay {b} with me |
| ~ | Sustain | forever~ |
| > | Push | >rise now |
| < | Soften | <easy now |
| ! | Accent | now! |
| >> | Forward push | >>move |
| ALL CAPS | Strong emphasis | NEVER |

Use only what you need. Too many markers can reduce clarity.

## 6. If Output Is Not Right

1. Keep your original prompt.
2. Change one variable at a time.
3. Re-test with short loops.
4. Compare to your last strong version.
5. Save every meaningful improvement.

## 7. One-Line Summary

My goal with SAION is to give regular people pro-level control over AI vocal performance by making emotion and delivery explicit.
