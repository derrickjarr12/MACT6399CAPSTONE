## 1. Opening Statement

SAION is not an AI music generator. I built it as a performance notation and control system that translates expressive musical intent into structured instructions AI music models can understand.

## 2. Who This Manual Is For

1. Creators and songwriters
2. Producers and vocal directors
3. Developers and technical collaborators
4. Researchers and evaluators
5. Partners, reviewers, and investors

## 3. Product Purpose

Most AI music workflows can process lyrics but miss performance intent.

I designed SAION to fill that gap by making delivery visible and controllable:

1. Emotional direction
2. Vocal character
3. Timing behavior
4. Phrasing and breath
5. Repeatable A/B iteration

## 4. Core Workflow

1. Create session and intent
2. Enter plain-language prompt
3. Apply emotion and vocal controls
4. Add optional notation details
5. Generate result
6. Save A/B versions
7. Compare and refine
8. Finalize strongest output

This flow keeps decisions clear and results repeatable.

## 6. Emotion Engine

I use the Emotion Engine to shape expressive contour without rewriting lyrics.

Focus dimensions:

1. Intensity
2. Vulnerability
3. Confidence
4. Tension
5. Warmth
6. Release

Guideline I follow: change one emotional variable at a time for clear comparative listening.

## 7. Vocal Performance Controls

These controls shape how the voice behaves in delivery.

Primary dimensions:

1. Delivery strength
2. Texture and grit
3. Breath presence
4. Runs and ornamentation
5. Timing placement
6. Warmth and release

Guideline I follow: start from a preset, then use micro-adjustments.

## 8. Performance Notation Language

I use SAION notation to add precision where plain prompts are too broad.

Use notation to indicate:

1. Breath points
2. Sustains
3. Push and release
4. Dynamic contrast
5. Emphasis

### 8.1 Reference Table

| Symbol | Meaning | Example | Interpretation |
|---|---|---|---|
| ^ | Lift | ^hold^ | Gentle local emphasis |
| {b} | Breath | stay {b} with me | Phrase breath marker |
| ~ | Sustain | forever~ | Extend trailing tone |
| > | Push | >rise now | Increase phrase energy |
| < | Soften | <easy now | Reduce phrase intensity |
| ! | Accent | now! | Add attack and stress |
| >> | Forward push | >>move ahead | Tighten and drive phrase |
| ALL CAPS | Hard emphasis | NEVER let go | Strong projection |
