# SAION Quick Start

Simple instructions for first-time users.

Live app:
https://saionapp-qsqlp.ondigitalocean.app/

Local app:
Run `npm start` and open http://localhost:3000

## What SAION Does

SAION helps you create, compare, and improve vocal-style results in a simple step-by-step flow.

## How To Use It

### 1. Open the App

Open SAION in your browser.

### 2. Start a Session

Type a session name.
Pick the general mood or style you want.

Examples:
- Warm
- Calm
- Cinematic
- Energetic

### 3. Enter Your Prompt

Type a short description of what you want.

Example:
- Soft emotional vocal with a smooth modern feel

### 4. Adjust Main Controls

If needed, change only the basic controls.
Keep your first setup simple.

You can adjust things like:
- Emotion
- Vocal feel
- Timing
- Effects

### 5. Generate

Choose a generator.
Click Generate.
Wait for the result.

### 6. Listen

Press play.
Listen from start to finish.
Decide what should change.

### 7. Improve It

Change one or two settings only.
Generate again.
Listen again.

Small changes work best.

### 8. Save Good Versions

Save the first strong version as A.
Save the next strong version as B.
Compare them.
Keep the better one.

### 9. Save or Export

Save your session.
Export your result if needed.
Use clear names.

Good names:
- Warm vocal test
- Brighter chorus try
- Final best version

## If Something Goes Wrong

1. Try again once.
2. Use a shorter prompt.
3. Change fewer settings.
4. Return to the last good version.

## Fast Daily Workflow

1. Open SAION.
2. Name the session.
3. Enter a simple prompt.
4. Click Generate.
5. Listen.
6. Make one small change.
7. Generate again.
8. Save the best version.
