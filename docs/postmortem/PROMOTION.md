## 5. Content Formats To Use In Those Channels

1. Before and after demo clips:
- Best for TikTok, YouTube Shorts, Instagram Reels
- Format: human intent sentence -> SAION notation block -> output result

2. Notation drops (code-first creative snippets):
- Best for Reddit, Discord, BandLab, Splice
- Format: small notation block with minimal framing to drive comments and remixes

3. Historical reframe posts:
- Best for Substack, LinkedIn, music-tech editorial outlets
- Angle: "Sound always had notation" and SAION as continuation, not disruption

4. Live notation sessions:
- Best for Twitch, YouTube Live, workshop contexts
- Format: co-write intent live, run prompt live, playback live
